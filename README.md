# Dulati Lingua AI — іске қосу нұсқаулығы

## Қазір жұмыс істейтін бөліктер
- Адаптивті веб-интерфейс, бөлімдер арасында ауысу.
- Сөздікке арналған AI сұрауы (API қосылғанда сөздің негізгі мағыналары, сөз табы, мысалдар сұралады).
- AI тіл көмекшісі, грамматика мұғалімі, сөйлеу практикасы және көңіл-күйді қолдауға арналған чат режимдері.
- Браузер қолдаса, микрофон арқылы сөйлеуді мәтінге айналдыру және жауапты дауыстап оқу.
- Сервердегі ортақ жалпы бет-кіру есептегіші. Бұл бірегей адамдар санын емес, бет ашылуларының жалпы санын есептейді.
- API кілті жоқ кезде сайт қатені ашық көрсетеді; жалған AI жауабын көрсетпейді.

## Қажет
- Node.js 18 немесе одан кейінгі нұсқа.
- Нақты AI функциялары үшін OpenAI API кілті және API есептік жазбасындағы қолжетімділік/төлем баптауы.
- Жалпы келушілер санын барлық адамға бірдей көрсету үшін сервері бар хостинг.

## Компьютерде іске қосу
1. ZIP файлын аш.
2. Жоба папкасында терминал/командалық жол аш.
3. `node --version` деп тексер.
4. `.env.example` файлын көшіріп `.env` деп ата.
5. `.env` ішіндегі `OPENAI_API_KEY=...` жолына өз API кілтіңді енгіз. Кілтті сайттың HTML файлына салма және ешкімге жариялама.
6. `npm start` орында.
7. Браузерден `http://localhost:3000` аш.

Node.js стандартты кітапханаларынан басқа npm пакеттері қажет емес.

## Қоғамға жариялау
Хостинг Node.js серверін жүргізуді қолдауы керек. Орта айнымалысы ретінде `OPENAI_API_KEY` орнат. Сервердің тұрақты жазылатын файл жүйесі болуы қажет, әйтпесе `data/visitors.json` хостинг қайта іске қосылғанда жоғалуы мүмкін. Масштабталған хостингке шығарғанда есептегішті PostgreSQL/Supabase/Firebase сияқты ортақ дерекқорға ауыстырған дұрыс.

## Маңызды
- API кілті жоқ кезде AI чаттары жұмыс істемейді; бұл сайттың қате емес, әдейі қойылған қауіпсіздік шарты.
- Қазіргі келушілер есептегіші жалпы бет ашылуларын есептейді, бірегей адамдарды емес. Боттар мен қайта жүктеулер де санға әсер етуі мүмкін.
- Сөйлеуді тану браузер мен құрылғыға тәуелді. Кей браузерлерде микрофон тек HTTPS немесе localhost-та жұмыс істейді; кейбір браузерлер сөйлеу деректерін өздерінің онлайн қызметі арқылы өңдеуі мүмкін.
- “Психологпен чат” бөлімі кәсіби психологтың орнына жүрмейді. Ол тек қолдау көрсетуге арналған AI көмекші. Жеке, аса сезімтал мәліметтерді енгізбе.
- Бұл университеттің ресми сайты емес, студенттік жобаның прототипі.
